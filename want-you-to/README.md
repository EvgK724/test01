# Want you to — тренажёр сложного дополнения

Веб-приложение для iPhone и iPad: правило **want + кого + to + глагол** («хочу, чтобы ты…»),
12 глаголов по этой схеме и 6 ловушек (make, let, suggest, insist, hope, say).

- **Правило** — объяснение, алгоритм выбора, примеры с контрастными парами, мнемоника.
- **Карточки** — интервальное повторение (1 → 3 → 7 → 16 дней), свайпы, озвучка.
  Режим «Тренировка: все карточки» не меняет расписание.
- **Тренировка** — 32 задания: собрать фразу из слов (с лишними словами-ловушками)
  и быстрый выбор. Ответ сразу, ошибки возвращаются, пока не будет верно.
- **Тест** — 10 заданий, ключ с объяснениями в конце.

Ссылка (GitHub Pages): https://evgk724.github.io/test01/want-you-to/

## Как поставить на экран «Домой»

1. Откройте ссылку в **Safari** на iPhone или iPad.
2. Нажмите «Поделиться» (квадрат со стрелкой вверх).
3. Выберите «На экран „Домой“» → «Добавить».

## Голос Microsoft Ryan

Фразы озвучиваются записями голоса Microsoft Ryan (`en-GB-RyanNeural`) из папки `audio/`.
Их создаёт GitHub Actions (`.github/workflows/ryan-audio.yml`) после каждого изменения
`index.html`; запустить вручную: вкладка **Actions** → **Ryan voice audio** → **Run workflow**.

Локально:

```
node want-you-to/tools/extract_phrases.mjs     # собрать фразы в phrases.json
pip install edge-tts
python want-you-to/tools/make_audio.py         # записать audio/*.mp3
```

Пока записей нет, звучит голос устройства (на iPhone и iPad — британский голос iOS;
лучше скачать «Daniel (улучшенный)» в Настройки → Универсальный доступ → Устный контент → Голоса).

## Файлы

- `index.html` — всё приложение (данные — блок `DATA-START … DATA-END` в начале скрипта).
- `tools/` — сбор фраз и генерация записей Ryan.
- `manifest.webmanifest`, `apple-touch-icon.png`, `icon-*.png` — иконка и режим приложения.
- `sw.js` — офлайн-кэш (вместе с записями).
