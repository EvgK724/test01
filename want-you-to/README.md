# Want you to — тренажёр сложного дополнения

Веб-приложение для iPhone и iPad: правило **want + кого + to + глагол** («хочу, чтобы ты…»),
12 глаголов по этой схеме, 6 ловушек (make, let, suggest, insist, hope, say),
карточки с интервальным повторением (1 → 3 → 7 → 16 дней) и озвучкой, тест на 10 заданий.

Ссылка (GitHub Pages): https://evgk724.github.io/test01/want-you-to/

## Как поставить на экран «Домой»

1. Откройте ссылку в **Safari** на iPhone или iPad.
2. Нажмите «Поделиться» (квадрат со стрелкой вверх).
3. Выберите «На экран „Домой“» → «Добавить».

Приложение открывается на весь экран, работает без интернета после первого открытия
и хранит прогресс на устройстве.

## Файлы

- `index.html` — всё приложение (данные карточек — массив `CARDS` в начале скрипта).
- `manifest.webmanifest`, `apple-touch-icon.png`, `icon-*.png` — иконка и режим приложения.
- `sw.js` — офлайн-кэш.
