# АТТ после ИИ — антитромботическая вторичная профилактика ишемического инсульта

Тренажёр для врачей по трудным вопросам:

- ДААТ (двойная антиагрегантная терапия; в КР — ДАТТ) и антиагреганты (CHANCE, POINT, THALES, CHANCE-2, INSPIRES, SAMMPRIS; интракраниальный стеноз — АСК 325 мг; ривароксабан 2,5 мг ×2 + АСК по КР и COMPASS);
- ФП: выбор ОАК; сроки старта ПОАК — по ELAN (размер инфаркта на КТ/МРТ), старая схема 1–3–6–12 (комментарий КР по ИИ 2024) — только для сравнения; до старта ПОАК — АСК; TIMING, OPTIMAS, CATALYST; доза ПОАК, инсульт на фоне ОАК;
- комбинации ОАК и антиагрегантов (AFIRE, AUGUSTUS), ESUS и предсердная кардиопатия (NAVIGATE, RE-SPECT, ARCADIA), субклиническая ФП (ARTESiA, NOAH);
- тромб в ЛП и ушке ЛП (X-TRA, RE-LATED AF, опросы EHRA, ESC 2024);
- антифосфолипидный синдром (КР по ИИ 2024, EULAR 2019, TRAPS, Ordi-Ros, ASTRO-APS, APASS);
- стентирование: ВСА (ESVS 2023), интракраниальные стенозы (SAMMPRIS, CASSISS), экстренный стент при тандемной окклюзии (STOP-CAD, ARTISTA), ФП + стент;
- открытое овальное окно: КР по ИИ 2024, ESO 2024, PASCAL, CLOSE, ФП после окклюдера, парадоксальная эмболия (Кулеш и соавт.);
- тромбоз глубоких вен голени: профилактика (КР по ИИ 2024, CLOTS 1 и 3), лечение и дистальный ТГВ (CHEST 2021, ESC 2019), антикоагулянт + АСК (EINSTEIN).

Опора — КР МЗ РФ «Ишемический инсульт и ТИА у взрослых» 2024 (главный источник), КР «Фибрилляция и трепетание предсердий» 2025, работы проф. А.А. Кулеша (2019, 2021, 2023, 2024), ESC 2024, ESO 2024 (ООО), ESVS 2023, CHEST 2021, EULAR 2019.
У каждого тезиса, карточки, случая и вопроса указан источник.

Разделы: **Разбор** (63 тезиса по 8 темам), **Карточки** (57 карточек, интервальное повторение 1 → 3 → 7 → 16 дней),
**Случаи** (40 клинических случаев с мгновенным разбором, фильтр по темам), **Тест** (26 вопросов, ключ в конце).

Ссылка (GitHub Pages): https://evgk724.github.io/test01/stroke-att/ · модуль «Медицины ПСО» (`med-pso/`).
Облик — как у остальных модулей «Медицины ПСО» и «Английского B2»: Georgia в заголовках, оранжевый акцент, вкладки сверху.

Учебный материал; не заменяет клинические рекомендации, инструкции к препаратам и решение лечащего врача.

Все данные — в блоке `DATA-START … DATA-END` в начале скрипта `index.html` (TOPICS, SOURCES, REVIEW, CARDS, CASES, TEST).
