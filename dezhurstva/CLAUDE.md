# Дежурства ПСО — график дежурств первичного сосудистого отделения

Приложение для телефона (тёмная неоновая тема): https://evgk724.github.io/test01/dezhurstva/ — GitHub Pages из `main`.
Вкладки: «Мои» (выбор себя, ближайшее дежурство, подписка на календарь с напоминаниями), «График» (кто дежурит сейчас;
месяц сеткой с двумя буквами фамилии, списком и «Нагрузка» — норма 1 ставки месяца и доля ставки каждого врача),
«Пожелания» (на следующий месяц до 15 числа), «Excel» (файл графика без телефонов и «Для печати» — с телефонами).
Организатор — пользователь (Клепиков). Короткая инструкция для врачей — `README.md`.

## Устройство

```
index.html            собранная страница (не править руками) — tools/build.py из tools/template.html + данных
data/schedule.json    опубликованные месяцы: doctors {id: {name, code?}} (code — две буквы для сетки, напр. «Лк»), months {"2026-11": {title, order, shift, off, duty, marks}}
data/config.json      адрес Google Формы для пожеланий (form.action = …/formResponse, form.entry = entry.ЧИСЛО), срок 15,
                      week_hours (39) — часы в неделю на 1 ставку для нормы; exclude — id врачей, которых нет в приложении
                      (их строки import_xlsx.py пропускает, compose.py их не ставит; сейчас: davydova)
cal/<id>.ics, all.ics календари для подписки (напоминания накануне в 19:00 и за час), часовой пояс Asia/Yekaterinburg
files/<месяц>.xlsx    Excel для вкладки «Excel»: одна таблица без телефонов и без примечаний (основа файла для печати);
                      у формул вписаны готовые значения — iPhone показывает итоги без пересчёта. files/hashes.json —
                      чтобы не пересобирать зря; поменяли оформление в make_xlsx.py — увеличьте XLSX_FORMAT в build.py
vendor/jszip.min.js   JSZip 3.10.1 (MIT): версия для печати собирается в браузере — к фамилиям добавляются телефоны,
                      которые организатор ввёл или взял из старого файла; телефоны живут только в localStorage его телефона
private/              ЧЕРНОВИКИ И ПОЖЕЛАНИЯ — в .gitignore, никогда не коммитить
tools/ru_calendar.py  производственный календарь РФ: праздники ТК ст. 112, переносы по постановлениям (TRANSFERS),
                      сокращённые дни; год из UNCONFIRMED — переносы не сверены с текстом постановления
tools/import_xlsx.py  готовый график из Excel (формат образца) → data → сборка; телефоны и лист пожеланий отбрасывает
tools/wishes.py       ответы Google Формы (CSV/XLSX/текст с «#DEZH {…}») → private/<месяц>-wishes.json
tools/compose.py      черновик по пожеланиям → private/<месяц>-draft.json, -report.txt, -wishes-text.json
tools/make_xlsx.py    Excel в оформлении образца; --full — с листом «Пожелания и итоги» (для организатора, не в git)
tools/publish.py      утверждённый черновик → data → сборка
tools/test.py         Playwright: вкладки, сетка, пожелания, ширины 320–1180, ошибки JS
```
Все команды — из корня репозитория. Нужны Python 3, openpyxl, Playwright с Chromium.

## Ежемесячно, 16-го: черновик на следующий месяц (задача «Дежурства ПСО: черновик графика»)

1. Месяц — следующий за текущим (16 ноября → декабрь). Если он уже есть в `data/schedule.json` — ничего не делать.
2. Пожелания. Google Drive: таблица ответов формы организатора («Untitled form (Responses)», её fileId — в тексте
   ежемесячной задачи) → `download_file_content` с `exportMimeType: text/csv` → раскодировать base64 в
   `dezhurstva/private/answers.csv` →
   `python3 dezhurstva/tools/wishes.py 2026-12 dezhurstva/private/answers.csv > dezhurstva/private/2026-12-wishes.json`.
   Берётся последняя отправка каждого врача до 15-го 23:59 (Екатеринбург); поздние — в `late`, решает организатор.
   Пожелания, пришедшие иначе (организатор переслал текст), — дописать в тот же JSON в том же формате.
3. Прочитать комментарии (`note`) и перевести их в структуру JSON: «все четверги» → `yesWd`, «3 субботы» → конкретные
   даты в `yes`, «одни сутки» → `full: {mode: eq, n: 1}`, «не ставить после ночи перед …» → даты в `no` и т. п.
   Врач без пожеланий, у которого в прошлом месяце не было дежурств, остаётся без дежурств (так делает compose.py).
4. Календарь РФ: `python3 dezhurstva/tools/ru_calendar.py 2027` — если «НЕ ПРОВЕРЕН», найти постановление
   Правительства «О переносе выходных дней в … году» (pravo.gov.ru, government.ru), поправить TRANSFERS, убрать год из UNCONFIRMED.
5. `python3 dezhurstva/tools/compose.py 2026-12 dezhurstva/private/2026-12-wishes.json` (`--fix 2026-12-05=klepikov`,
   `--zero id`, `--exclude id`). Прочитать отчёт: дни без дежурного, невыполненные пожелания, «через день». Улучшить,
   если можно (перезапуск с --fix), и честно перечислить, что выполнить не удалось и почему.
6. Excel для организатора: `python3 dezhurstva/tools/make_xlsx.py 2026-12 --draft dezhurstva/private/2026-12-draft.json
   --full dezhurstva/private/2026-12-график-черновик.xlsx --wishes dezhurstva/private/2026-12-wishes-text.json`.
   Без телефонов: они нужны только в версии для печати (оперативный отдел), а её организатор делает сам
   во вкладке «Excel» → «Для печати». Телефоны никуда не копировать и не публиковать.
7. Отправить организатору файл (SendUserFile) и коротко отчёт по-русски; спросить, утверждает ли.
   **Ничего не публиковать до явного «утверждаю» организатора.** Правки — внести (--fix или правка draft.json), прислать снова.
8. После «утверждаю»: `python3 dezhurstva/tools/publish.py 2026-12` (или `import_xlsx.py ФАЙЛ.xlsx`, если организатор
   прислал исправленный Excel) → `python3 dezhurstva/tools/test.py` → commit → `git push origin HEAD:main` и в рабочую
   ветку. Приложение и календари обновятся у всех сами.

## Готовый график из Excel (как ноябрь 2026)

`python3 dezhurstva/tools/import_xlsx.py ФАЙЛ.xlsx` → проверить сводку (врачи, дни без дежурного, расхождения заливки
с календарём РФ) → `python3 dezhurstva/tools/test.py` → commit, push в main. Месяц из файла заменяет тот же месяц.

## Правила

- Телефоны и пожелания — личные данные: не в репозиторий (он публичный), не на сайт. В приложении — только фамилии.
- Выходные и праздники — только по `ru_calendar.py`: сб/вс и праздники — сутки 08:00–08:00, будни 16:18–08:00
  (время смен — из графика, `shift`). Сокращённые предпраздничные дни: начало дежурства не меняется, норма −1 ч.
- Норма часов — своя у каждого месяца: week_hours / 5 × рабочие дни месяца по календарю РФ − сокращённые
  предпраздничные часы (ноябрь 2026: 39 / 5 × 20 − 1 = 155 ч); доля ставки = часы дежурств / норму.
- Один дежурный в день, не два дня подряд.
- Размер шрифта следует настройке телефона: на iPhone — Dynamic Type (меряется шрифт -apple-system-body, ×0,85–1,5),
  на Android — метка `<meta name="text-scale">`. Тест проверяет раскладку при обычном шрифте, ×1,15 и ×1,4.
