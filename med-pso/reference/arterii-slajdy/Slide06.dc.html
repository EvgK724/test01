У 15–30 % людей ЗМА получает кровь преимущественно из ВСА через ЗСА (фетальный тип) — тогда «задний» инфаркт возникает из каротидного бассейна
СИНДРОМЫ ПОРАЖЕНИЯ
Корковые ветви (P4)
Гомонимная гемианопсия на противоположной стороне с сохранением макулярного зрения; зрительные агнозии.
Доминантная затылочная доля
Алексия без аграфии — при вовлечении валика мозолистого тела.
Таламический (Дежерина–Русси)
На противоположной стороне: гемигипестезия, затем жгучая боль, гиперпатия, гемиатаксия; таламоколенчатая а.
Артерия Першерона
Вариант (≈4–12 % людей): один ствол от P1 питает парамедианные отделы обоих таламусов ± ростральный средний мозг. Окклюзия: угнетение сознания, парез взора вверх, амнезия. КТ в первые часы часто без изменений → DWI; «V-признак» — при вовлечении среднего мозга.

Двустороннее поражение затылочных долей — корковая слепота; при отрицании дефекта — синдром Антона
