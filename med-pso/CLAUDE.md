# Медицина ПСО — семь приложений, которые нужно объединить в одно

Здесь собраны все приложения по медицине, сделанные для врачей-неврологов первичного сосудистого отделения (ПСО).
Каждое — отдельная страница для iPhone и iPad: тёмная тема, тренировка карточками с интервальным повторением и
вкладка «Справочник» с калькулятором. Сейчас каждое опубликовано отдельным артефактом claude.ai и ставится
своей плиткой на экран «Домой».

**Задача: собрать из них одно рабочее приложение** — одна плитка, одна главная страница, общий поиск и общее
повторение, при этом ни один модуль не теряет справочник, калькуляторы, тренировку и источники.

КТ-перфузия: `python3 ctp/mk_template.py && python3 ctp/build.py` (её шаблон — основа остальных: после правки
пересобрать всех). Нужны Python 3, Playwright с Chromium, Pillow; для `overlap.py` — шрифты DejaVu.
Сборка проверена: из этой папки все шесть генераторов дают страницы, байт в байт совпадающие с опубликованными.

## Как устроен модуль

- Две вкладки: «Тренировка» и «Справочник». Тренировка: темы по группам (`GROUPS`), у темы — правило (`rule`,
  абзацы через `\n\n`) и примеры (`ex`); карточки `c(id, тема, вопрос с одним ___, варианты, ответ, пояснение)`;
  последняя тема (`MIXED_TOPIC`) — «Итог», 15 случайных карточек. Интервалы повторения `[1, 3, 7, 16]` дней.
- Разметка в примерах: `[текст]` — оранжевый акцент, `[текст|b]` — зелёный, `[текст|g]` — синий.
- Справочник: HTML собирается в `mk_template.py` (строки-вставки `<!--__ИМЯ__-->` заполняет `build.py` из таблиц
  `content.py`), калькулятор — JS-строка `CALC` там же. Помощники калькулятора (`tp`, `line`, `row`, `pill`, даты)
  повторяются в каждом модуле, глобальные имена (`pc`, `renderPlan`, `initCalc`) и id (`#pcalc`, `#pres`, `#rule`,
  `#drill`, `#topics`, `#go`) совпадают — **в одну страницу модули без изоляции не сложить**.
- `build.py`: `typo()` расставляет неразрывные пробелы (числа с единицами, предлоги, тире, «КР по ИИ 2024»,
  знаки сравнения; после «;» перед «<» перенос разрешён), U+2060 после тире в диапазонах (25–50), мягкие переносы
  в самых длинных словах; переводит `px` в стилях в `calc(px*var(--k))` — масштаб на iPad.
- Прогресс: `localStorage` (ключи `<модуль>:state/tab/open`, у «АТТ» — `stroke-att.progress.v1`) и облако
  через `window.claude` (`db` + `user`). **Все семь модулей пишут в один и тот же документ
  `data/users/<uid>/progress`** — внутри одного артефакта они затрут друг друга.
- «Артерии мозга» сложнее остальных: интерактивные схемы сосудов (`views.py`, `atlas.css`), карточки с рисунком
  и с нажатием на сосуд (`fig`, `tap`), окраска сосудов по категориям ВСТЭ; есть вариант для GitHub Pages
  (`art/site/`, `mk_site.py`: manifest, service worker).
- «АТТ после инсульта» сделан в другом чате и устроен иначе: вкладки «Карточки», «Случаи», «Тест», «Трудные места»,
  данные в константах внутри страницы (`TOPICS`, `CARDS`, `CASES`, `TEST`, `REVIEW`, `SOURCES`), генератора нет.
  Его факты в этом пакете не перепроверялись.

## Что сделать

### Обязательно

1. Одна точка входа: главная с плитками модулей по двум группам (`catalog.json → groups`), поиск по названиям,
   темам и карточкам всех модулей, «Сегодня к повторению» — всего и по модулю, возврат на главную одним касанием,
   запоминание последнего модуля.
2. Каждый модуль работает полностью: справочник, все калькуляторы, тренировка, темы, источники.
3. Прогресс не смешивается: у каждого модуля свой документ в облаке (`data/users/<uid>/progress-<ключ>`),
   свои ключи `localStorage`; id карточек в общем поиске и повторении — с префиксом модуля.
4. iPhone и iPad: работает при ширине 320–430 и на iPad в обеих ориентациях, safe area, без горизонтального скролла,
   полноэкранная плитка на «Домой».
5. Модули грузятся по требованию — главная открывается быстро.

### Рекомендуемый путь

**Этап 1 — оболочка, модули без изменений.** Так уже сделан «Английский B2» (46 тренажёров), и это работает на iPhone
и iPad: `reference/english-b2-shell.html`. Оболочка по `fetch("apps/<ключ>.html")` берёт тело модуля
(это `sources/<папка>/index.html` — без каркаса) и кладёт в `iframe.srcdoc` с общим `<head>`; `srcdoc` наследует
origin, поэтому `localStorage` общий. Первой строкой, до своих скриптов, модуль вызывает мост оболочки
(`parent.__eng.attach(key, window)` в образце), и тот подставляет ему `window.claude = claudeFor(key)` — прокси,
которое переименовывает документ прогресса в `progress-<ключ>` (`mapPath`). Эту строку при сборке добавить в каждый
модуль. Счётчики на главной оболочка считает, читая `localStorage` модулей по ключам из каталога. Это даст рабочее
приложение быстро и без риска для фактов.

**Этап 2 — общий движок (по желанию, после этапа 1).** Вынести общий код (тренажёр, стили, `typo()`, помощники
калькуляторов) в один генератор, модуль = `content.py` + справочник + калькулятор в своём пространстве имён.
Один `build`, один набор тестов, нет 6 копий движка по ~70 КБ. Делать, только если этап 1 стабилен.

### Содержание: свести, но не выдумывать

- «АТТ после инсульта» пересекается с «Антиагрегантами» (ДААТ/ДАТТ) и «Ранней антикоагуляцией» (ФП, сроки).
  Сравнить по фактам. Расхождения не сглаживать молча — показать врачу списком и спросить.
- Термин: в КР по ИИ 2024 — «ДАТТ», в модулях этого пакета — «ДААТ (в КР — ДАТТ)», в «АТТ» — «ДАТТ». Выбрать один.
- Проверить «АТТ» на соответствие протоколу ПСО: в отделении принят протокол **ранней** антикоагуляции
  (ELAN, CATALYST, OPTIMAS); правило «1–3–6–12» не применяется.
- В КТ-перфузии остался код озвучки из английского шаблона (`speechSynthesis`, `ctp:autospeak`) — выяснить, нужен ли.

## Правила содержания (не нарушать)

- Источник называть точно: «КР по ИИ 2024» (Минздрав, 814_1), «КР по ФП 2025» (382_2), «КР по ДЛП 2023» (752_1),
  с УУР/УДД, если они есть. Не приписывать КР то, чего в них нет: каждая фраза «по КР …» сверяется с текстом
  (`sources/kr/cr814.txt`, `sources/oac/src/cr382_2.txt`, `sources/vits/src/cr752.txt`).
- Любой новый или изменённый факт (число, порог, доза, класс рекомендации, результат РКИ) — только со сверкой
  по первоисточнику. Нет источника — не писать или пометить как мнение. Статьи — со ссылкой на DOI.
- Лекарства: МНН со строчной буквы, торговое название — в скобках: «клопидогрел (Плавикс)».
- Контекст ПСО: ранняя антикоагуляция (не «1–3–6–12»); своя ангиографическая служба — решение о ВСТЭ принимает
  невролог ПСО, в РСЦ не переводят.
- В подвале каждого модуля — дата сверки; при изменении фактов обновить.

## Правила вёрстки

- Тёмная тема: фон почти чёрный, текст `#e8e8e8` (не чисто белый), акцент `#d97757`, синий `#7cc0dd`,
  «да» — `--yes-text`, «нет» — `--no-text`, «с условием» — `#e5c07b`. Заголовки — serif, текст — системный sans.
- Крупный шрифт, цели касания не меньше 44×44, основное управление — внизу, под большой палец.
- Неразрывные пробелы по правилам `typo()`; ни одного разрыва слова в кнопках и чипах; длинные слова — мягкий перенос.
  Текст не обрезается и не вылезает из своего блока.
- Проверять ширины 320, 375, 390, 430 и iPad 820×1180, 1180×820.

## Проверка перед сдачей

  (сохранить вывод до изменений и сравнить), карточки отвечаются, ошибок JS нет.

## Публикация

Объединённое приложение публикуется как один артефакт claude.ai (страница + файлы `apps/*.html`), возможности
`db` и `user`. Публикует сессия Claude с инструментом артефактов: прислать туда готовую папку и попросить опубликовать.
Плитка: `python3 mkprofile.py <папка> <ключ> "<подпись>" "<url>" "Медицина: …" "<описание>"`.
Прогресс из старых артефактов в новый сам не перейдёт (у каждого артефакта своё хранилище). Старые артефакты не
удалять, пока новое приложение не проверено на iPhone и iPad.
