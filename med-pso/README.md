# Медицина ПСО — пакет для Claude Code

Семь приложений для неврологов ПСО в одном месте: Артерии мозга, КТ-перфузия, Ранняя антикоагуляция (ПОАК),
ВИТС после инсульта, Антиагреганты при ИИ и ТИА (ДААТ), Антитромботики при тромбоцитопении, АТТ после инсульта.
Задача для Claude Code — объединить их в одно приложение; задание и все правила — в `CLAUDE.md`.

## Три архива — в одну папку

- `med-pso.zip` — приложения, генераторы, плитки, задание (`CLAUDE.md`);
- `med-pso-istochniki-1.zip` и `med-pso-istochniki-2.zip` — КР и статьи для сверки фактов.

Распаковать все три в одно место (Терминал на Mac):

```
cd ~/Downloads && for f in med-pso*.zip; do unzip -o -q "$f"; done
```

Получится папка `~/Downloads/med-pso`.

## Открыть в Claude Code

- в приложении Claude: вкладка **Code** → выбрать папку `med-pso`;
- или в Терминале: `cd ~/Downloads/med-pso && claude`.

Первое сообщение: «Прочитай CLAUDE.md и объедини приложения в одно — начни с этапа 1».

## Посмотреть локально

```
cd med-pso/app && python3 -m http.server 8000
```

Открыть http://localhost:8000 — объединённое приложение (этап 1). Отдельные страницы модулей — в `site/`.

## Пересобрать и проверить

```
cd med-pso/sources
python3 shell/build.py     # модули → app/apps, каталог, поиск, иконки
python3 shell/test.py      # каждый модуль из главной, прогресс progress-<ключ>, поиск, ширины 320–1180
```

Опубликовано: https://claude.ai/artifact/HQzVkSJxBdvv1jGfFXgKjY · плитка на «Домой» — `tiles/pso.mobileconfig`.
