# Медицина ПСО — проект для ChatGPT/Codex

Восемь приложений для неврологов ПСО в одном месте: Артерии мозга, КТ-перфузия, Ранняя антикоагуляция (ПОАК),
ВИТС после инсульта, Антиагреганты при ИИ и ТИА (ДААТ), Антитромботики при тромбоцитопении, АТТ после инсульта, Где очаг.
Объединённое приложение уже работает; устройство проекта и все правила — в [AGENTS.md](AGENTS.md).

## Три архива — в одну папку

- `med-pso.zip` — приложения, генераторы и плитки (для работы используйте актуальные файлы репозитория и `AGENTS.md`);
- `med-pso-istochniki-1.zip` и `med-pso-istochniki-2.zip` — КР и статьи для сверки фактов.

Распаковать все три в одно место (Терминал на Mac):

```
cd ~/Downloads && for f in med-pso*.zip; do unzip -o -q "$f"; done
```

Получится папка `~/Downloads/med-pso`.

## Работа в ChatGPT/Codex

Откройте репозиторий `test01` в Codex и укажите папку `med-pso`. Перед изменениями прочитайте [AGENTS.md](AGENTS.md).
Этап 1 объединения уже выполнен; дальнейшие задачи относятся к поддержке существующего приложения.
Сохранённые публикации, профили плиток, данные и совместимость синхронизации остаются частью проекта.

## Посмотреть локально

```
cd med-pso/app && python3 -m http.server 8000
```

Открыть http://localhost:8000 — объединённое приложение (этап 1). Отдельные страницы модулей — в `site/`.

## Пересобрать и проверить

```
cd med-pso/sources
python3 shell/build.py     # модули → app/apps, каталог, поиск, иконки
python3 shell/test.py      # каждый модуль из главной, прогресс progress-<ключ>, поиск, ширины 320–1180
```

Основная рабочая версия: https://evgk724.github.io/test01/med-pso/app/ (GitHub Pages из `main`, прогресс на устройстве).
Сохранённая публикация: https://claude.ai/artifact/HQzVkSJxBdvv1jGfFXgKjY · её плитка на «Домой» — `tiles/pso.mobileconfig`.

## Опубликовать

После согласованных изменений пересоберите нужные модули и оболочку, выполните проверки из `AGENTS.md`,
проверьте diff и опубликуйте изменения в существующей ветке `main` для GitHub Pages.
Профиль плитки на экран «Домой» создаёт `sources/mkprofile.py`; существующие плитки и публикации сохраняются.
