# Коллокации

**Ссылка:** https://evgk724.github.io/test01/kollokatsii/

Тренажёр английских коллокаций — слов, которые «дружат» (*make a decision*, *heavy rain*, *a fierce temper*) —
по урокам 6–60 книги English Collocations in Use (Intermediate): 55 тем, около 1700 коллокаций.
Объяснения, примеры, переводы и задания написаны заново; из книги взяты темы и сами сочетания.

- **Уроки** — главная мысль урока, коллокации по разделам с переводом и примером, частые ошибки.
  🔊 и нажатие на пример — озвучка; «Скрыть перевод» — проверить себя; в конце урока — «Карточки урока» и «Тренировка урока».
- **Карточки** — «к повторению сегодня», все уроки или один урок; можно начинать с русского.
  «Не знаю» (смахнуть влево) — ещё раз в этом же заходе, «Почти» — завтра, «Знаю» (вправо) — через 1, 3, 7, 16 дней.
- **Тренировка** — 10 заданий: вставить слово в пример и выбрать коллокацию по переводу; ошибки — ещё раз в конце раунда.
- **Поиск** — по-английски и по-русски, нажатие открывает коллокацию в уроке.
- **Озвучка** — записи Microsoft Ryan, если они есть в `audio/`, иначе голос телефона (лучший британский).
  В «?» — «Озвучивать сразу» и «Медленнее». Записей пока нет: 27 октября 2026 сервис отвечает workflow
  «Ryan voice audio» (edge-tts 7.2.8) ошибкой 403, а обходить защиту Microsoft новой версией edge-tts мы не стали.
- **Оформление** — как у «Футов и фунтов»: тёмная неоновая тема, стеклянное нижнее меню с «каплей», текст уходит под часы;
  на iPad — на всю ширину и крупнее; шрифт следует настройке размера текста телефона.

Прогресс хранится на телефоне (localStorage), сеть нужна только для обновлений и первой загрузки записей.

## Файлы

- `units/uNN.js` — уроки. Строка коллокации: `коллокация с {ключевым словом} | перевод | пример с [коллокацией] и {пропуском} | три неверных варианта | заметка`.
  В текстах `*так*` — выделение, `~так~` — ошибка (зачёркнуто).
- `tools/template.html` — приложение; `python3 kollokatsii/tools/build.py` — сборка `index.html` и проверка данных (`tools/check.mjs`).
- `python3 kollokatsii/tools/test.py` — проверка в Chromium: все уроки, карточки, тренировка, поиск, ширины 320–1180, крупный текст.
- Озвучка: `tools/extract_phrases.mjs` → `phrases.json`, `tools/make_audio.py` → `audio/` (делает GitHub Actions,
  workflow «Ryan voice audio», после изменения `index.html`; за один запуск — до 100 минут, остальное — в следующий).
- `tools/icon.py` — иконка; `sw.js` — офлайн-кэш (записи кэшируются при первом прослушивании).
